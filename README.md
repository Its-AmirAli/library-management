# Library Management
A simple library management system written in Python.

## Features
- Add books
- Add members
- Generate unique IDs for books and members
- Display books
- Display members


## How to Run
- Clone the repository:
```bash
git clone git@github.com:Its-AmirAli/library-management.git
```
- Go to the project directory:
```bash
cd library-management
```
- Run the program:
```bash
python main.py
```
or 
```bash
python3 main.py
```
## About
- This project is a learning project built to practice Python, object-oriented programming (OOP), file handling, JSON, and Git/GitHub.
